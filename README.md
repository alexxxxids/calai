# CalAI — ветка `calendar-mvp` (Frontend + localStorage)

Облегчённая учебно-рабочая ветка проекта CalAI для 2-месячного этапа разработки вдвоём (без бэкенда, Supabase, авторизации и ИИ).

## Что оставлено в этой ветке

* **Единственная рабочая страница (`/`):** интерактивный календарь на базе FullCalendar (`День / Неделя / Месяц`).
* **Панель задач (бэклог):** создание, редактирование, завершение и удаление задач; перетаскивание задач мышкой прямо в сетку календаря (Drag & Drop); простая клиентская кнопка авто-расстановки «Zaplanuj».
* **Управление блоками:** перемещение и изменение длительности блоков в календаре, закрытие прошедших блоков (`Wykonano / Nie wykonano / Usuń`), верхний баннер незакрытых блоков.
* **Правая панель:** мини-календарь, фильтры по типам задач, диалог постоянного расписания («Plan lekcji»), чек-лист привычек на день.
* **Хранилище:** все данные сохраняются локально в `localStorage` браузера; кнопка **«Resetuj demo»** в шапке возвращает стартовый набор задач.

## Запуск

```bash
npm install
npm run dev
```

Открыть в браузере: `http://localhost:3000`
